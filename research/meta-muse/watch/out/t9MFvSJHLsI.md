
### 3. Step-by-Step UI Actions

1. **Claude:** Paste Master Prompt -> Enter custom topic -> Select palette option `Option 3: High-Contrast Academic` -> Generate image & motion prompts.
2. **Google Flow:** Turn on **Agent mode** -> Set image default (`Nano Banana 2`, `9:16`) and video default (`Omni 1.1 Flash`, `9:16`) -> Paste 11 batch image prompts -> Generate visuals -> Rename images `S-01` through `S-11`.
3. **Google Flow:** Drag `S-01`–`S-11` into prompt window as image references -> Paste batch video animation instructions -> Generate 11 video clips -> Download MP4s.
4. **ElevenLabs:** Open Text-to-Speech -> Paste formatted 11-line script -> Select voice (*James*) -> Generate & download MP3 voiceover.
5. **CapCut Desktop:** Import voiceover & MP4 clips -> Change aspect ratio to `9:16` -> Insert cream solid color background track -> Trim clips to match voiceover beats -> Set 5-frame opacity keyframes (`100%` to `0%`) at clip ends -> Apply slide transitions -> Group clips into a Compound Clip -> Add background music & SFX -> Export at `1080p, 30fps`.

### 4. Visual Style Description

* **Format & Layout:** Vertical 9:16 editorial mixed-media style.
* **Palette:** Pale cream textured paper background with subtle grid lines, paired with terracotta/orange geometric accents, charcoal serif headlines, and bold block captions.
* **Objects & Motion:** Floating photorealistic 3D objects (fishing hook, marble brain with glowing center, wooden gap blocks, puzzle pieces). Features slow 2.5D parallax drift, kinetic text pop-ins, smooth slide transitions, and quick fade-to-cream cut points.
